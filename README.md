# Wortreise iOS

Wortreise ("word journey") is an iOS app for discovering and learning German words, one step at a time.

## Bugs and Feature Requests

We use [GitHub Issues](https://github.com/marcelbirkner/wortreise-ios/issues) to track bugs and feature requests.

- **Found a bug?** Open an issue and describe what happened, what you expected, and the steps to reproduce it. Include your iOS version and device model if possible.
- **Have an idea?** Open an issue describing the feature and the problem it solves.

Please search existing issues first to avoid duplicates.
